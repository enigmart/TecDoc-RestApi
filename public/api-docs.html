🚀 TecDoc API v2 Documentation

Complete REST API for TecDoc vehicle parts database with authentication, caching, and comprehensive data access.

Base URL
http://koupkastecdoc.gr/tecdoc-api/public/api/v2

🔐 Authentication

All API endpoints (except token creation) require authentication using Bearer tokens.

Required Header
Authorization: Bearer YOUR_TOKEN_HERE
Token Features:
  • Duration: 30 days
  • Rate Limit: 1000 requests/hour
  • Scopes: read, write, admin
  • Auto-refresh: Available

POST /v2/auth/create-token

Create a new API authentication token

Request Body:
{
  "name": "My API Token",
  "scopes": ["read", "write"]
}
Response Example:
{
  "success": true,
  "message": "API token created successfully",
  "data": {
    "token": "tecdoc_3ddMA3ejtIChy9qvWdGCwlLvHvFlqVLiVX1W4Q76MSZU63ACtJGHXoTUdfwi",
    "name": "My API Token",
    "scopes": ["read", "write"],
    "expires_at": "2025-12-24T11:35:39.000000Z",
    "requests_limit": 1000
  },
  "meta": {
    "token_id": 1,
    "created_at": "2025-11-24T11:35:39.000000Z"
  }
}
cURL Example:
curl -X POST "http://koupkastecdoc.gr/tecdoc-api/public/api/v2/auth/create-token" \
  -H "Content-Type: application/json" \
  -d '{"name":"My API Token","scopes":["read","write"]}'

  • Cache TTL: 30 minutes

📊 Light vs Full Modes

Light Mode (Default)
  • Essential data only
  • Faster response times
  • Lower bandwidth usage
  • Perfect for dropdowns/lists

Usage: ?mode=light or no parameter

Full Mode
  • Complete data sets
  • Additional metadata
  • Rich information
  • Perfect for detailed views

Usage: ?mode=full

⚡ Rate Limiting

Current Limits
  • Requests: 1000 per hour
  • Reset: Every hour from first request
  • Headers: X-RateLimit-* in all responses
Rate Limit Headers:
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 995
X-RateLimit-Reset: 1763989138
Rate Limit Exceeded Response:
{
  "success": false,
  "message": "Rate limit exceeded",
  "error": "RATE_LIMIT_EXCEEDED",
  "meta": {
    "requests_limit": 1000,
    "reset_at": "2025-11-24T13:00:00.000000Z"
  }
}

🚀 Caching Strategy

Endpoint Cache Time Strategy Reason
Vehicle Types 2 hours Static Long Rarely changes
Part Categories 2 hours Static Long Rarely changes
Manufacturers 1 hour Semi-Static Occasionally updated
Models/Versions 1 hour Semi-Static Occasionally updated
Article Details 30 minutes Standard May be updated
Search Results 15 minutes Dynamic Short Frequently changing
Client-Side Caching:
  • Use ETag for conditional requests
  • Respect Cache-Control headers
  • Check X-Cache-TTL for optimal timing
